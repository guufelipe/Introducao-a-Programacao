# Introducao-a-Programacao
Este repositório contém os exercícios desenvolvidos ao longo da disciplina -Introdução à Programação- (2022.2), com foco nos fundamentos da programação e princípios de Programação Orientada a Objetos (POO), usando Python.

# Conteúdo Abordado
A disciplina foi dividida em listas temáticas, cada uma abordando um tópico central da programação:

1. -Condicionais-
2. -Laços de Repetição-
3. -Listas-
4. -Funções-
6. -Recursão-
7. -Tuplas e Dicionários-

Cada lista contém:
-  Enunciados -> das questões propostas.
-  Códigos -> de solução das respectivas questões.
